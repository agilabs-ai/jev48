# Jev48 Public Benchmark Results

Aggregate result receipts from an open, auditable reproduction of TypeSafe's Jev typed probabilistic decision model.

This dataset contains the six public benchmark summary JSON files, the release manifest, benchmark registry, methodology, citation metadata, and third-party notices. It covers 6,300 evaluated decisions or cases and does not republish restricted row-level inputs or predictions.

Canonical report: https://getedge.cc/jev48/

Source and model: https://github.com/edgelabs-ai/jev48

Jev48 is independent and not affiliated with TypeSafe.
